# Web-Development-KN-41

Репозиторій із виконаними лабораторними роботами з предмета «Веб-програмування» студента групи КН-41 Форемського Ореста.

## Структура репозиторію
- `index.html` - головна сторінка-навігатор репозиторію для GitHub Pages.
- `lab_1/my-best-cities/` - **Лабораторна робота №1**: Мої найкращі міста (Статичний блог).
- `lab_2/` - **Лабораторна робота №2**: Акустична варта (Базова верстка).
- `lab_3/` - **Лабораторна робота №3**: Акустична варта (Адаптивність, SCSS, Grid, Flexbox).
- `lab_4/` - **Лабораторна робота №4**: Акустична варта (JavaScript, Console API, Цикли, Функції).
- `lab_5/` - **Лабораторна робота №5**: Акустична варта (ООП, Класи, Модулі ES6).
- `lab_6/` - **Лабораторна робота №6**: Акустична варта (Відображення та фільтрація в DOM).
